# **Tempelis**

<p align="center">
  <a href="url"><img src="https://github.com/ThanosVk/Tempelis/blob/master/assets/icon/icon.png" align="center" height="480" width="480" ></a>

Ever thought about having an image that you need to use or see every day because of a habit or a
circumstance, that is exactly why this application is built for. Tempelis (greek word for calling 
someone lazy) application helps you by keeping an image that you have selected, all you have to do 
is to select an image from the gallery and every time you open the app tha image is right there for 
you. Works for Android 10 and newer versions. You can download the application by clicking 
[here](https://github.com/ThanosVk/Tempelis/raw/master/Android%20app/Tempelis.apk).
